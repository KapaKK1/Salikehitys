# Salikehitys PWA

Julkaise koko kansion sisältö HTTPS-palveluun. Helpoin: Netlify Drop, GitHub Pages tai Azure Static Web Apps.

## Netlify Drop
1. Pura ZIP.
2. Avaa https://app.netlify.com/drop tietokoneella.
3. Pudota purettu salikehitys-pwa-kansio sivulle.
4. Avaa saatu HTTPS-osoite puhelimella.
5. Android/Chrome: valikko > Asenna sovellus. iPhone/Safari: Jaa > Lisää Koti-valikkoon.

Tieto tallentuu tämän version selaimen localStorageen. OneDrive-synkronointi vaatii erillisen Microsoft Entra -sovellusrekisteröinnin eikä sisälly tähän pakettiin.
